# Number Patterns Practice — Grade 4 CAPS

An interactive, browser-based learning tool to help Grade 4 learners master number patterns as required by the South African CAPS curriculum.

## What's Included

| File | Description |
|------|-------------|
| `number-patterns.html` | Interactive practice tool — open in any browser, no internet needed |
| `PARENT-GUIDE.md` | Detailed strategies and tips for parents helping their child |

## How to Use

1. **Open `number-patterns.html`** in any modern web browser (Chrome, Edge, Firefox, Safari).
2. No installation or internet connection required — everything runs locally.
3. Read through the **Learn** tab together with your child first.
4. Move to **Practice** on Easy, then gradually increase difficulty.
5. Use **In-Out Tables** to practise finding rules.
6. Try the **60-Second Challenge** for a fun speed round.

## Features

- Aligned to **CAPS Grade 4** number pattern requirements
- Four modes: Learn, Practice, Input-Output Tables, and Challenge
- Three difficulty levels (Easy, Medium, Hard)
- Immediate feedback with hints
- Score tracking and streaks
- Works offline — just a single HTML file
- Mobile-friendly design

See [PARENT-GUIDE.md](PARENT-GUIDE.md) for detailed strategies on how to support your child with number patterns, common mistakes to watch for, and a suggested weekly practice schedule.
