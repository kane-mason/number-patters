What Is a Number Pattern?

A number pattern is a list of numbers that follows a rule. The rule tells you how to get from one number to the next.

2, 4, 6, 8, 10, ...
Rule: Add 2 each time (+2)

To find the rule, look at what happens between numbers. Ask: "What did I do to get from this number to the next?"

Step-by-Step: Finding the Rule

  1. Write the differences. Subtract each number from the next one.
    5, 9, 13, 17, 21
    9−5 = 4,   13−9 = 4,   17−13 = 4,   21−17 = 4
    The difference is always 4 → Rule: +4
  2. Check if it's going up or down.
    30, 25, 20, 15, 10
    25−30 = −5 (getting smaller!)
    Rule: Subtract 5 each time (−5)
  3. Use the rule to find missing numbers.
    3, 6, ?, 12, 15
    The rule is +3, so the missing number is 6 + 3 = 9

Counting Patterns (CAPS Grade 4)

In Grade 4 you need to count forwards and backwards in these patterns:

Count in 2s: 2, 4, 6, 8, 10, 12, ...
Count in 3s: 3, 6, 9, 12, 15, 18, ...
Count in 4s: 4, 8, 12, 16, 20, 24, ...
Count in 5s: 5, 10, 15, 20, 25, 30, ...
Count in 10s: 10, 20, 30, 40, 50, ...
Count in 25s: 25, 50, 75, 100, 125, ...
Count in 50s: 50, 100, 150, 200, ...
Count in 100s: 100, 200, 300, 400, ...
These are like the times tables — if you know your tables, you already know these patterns!

Input–Output Tables (Number Machines)

A number machine takes a number in and does something to it. You need to figure out what the machine does!

Input (In)→ Rule: ×3Output (Out)
22 × 36
55 × 315
88 × 324
To find the rule, ask: "What do I do to the input to get the output?"

Patterns That Don't Start at the Beginning

Sometimes patterns start at a number other than the "usual" one:

7, 12, 17, 22, 27, ...
Rule: Start at 7, then add 5 each time (+5)

The starting number and the rule are both important!

Tips for Parents 👨‍👩‍👧

  • Use physical objects — beads, coins, blocks. Build the pattern with hands first.
  • Write the "jumps" between numbers on a number line. This makes the rule visible.
  • Start easy (+2, +5, +10) and build up gradually.
  • Practise daily for 5–10 minutes — short and frequent is better than long and rare.
  • Make it a game — "I say a number, you say the next one!" Use the practice & challenge tabs here.
  • Look for patterns in real life — house numbers, money (R5, R10, R20), time.
  • Don't rush — if she gets stuck, go back to the concrete (objects) level before abstract numbers.
